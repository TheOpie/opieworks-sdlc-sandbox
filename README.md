# opieworks-sdlc-sandbox

A tiny TypeScript component library. It exists only so that the opieworks-sdlc
stages have a real repo to set up, run, and gate.

- `pnpm install`
- `pnpm verify` runs the type check and the tests.

Agents act here only as the bot `opieworks-sdlc-bot`. A human approves and merges.
